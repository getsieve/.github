# Sieve

**Credentials stay in Europe.**

Sieve is an open-source checkpoint for AI tools. It catches passwords, API keys and other credentials before your prompts, files and agent context are sent to AI providers like Anthropic, OpenAI or xAI.

- **Runs on your machine.** Detection happens locally, before anything leaves.
- **Inspected, never kept.** Nothing Sieve inspects is stored or sent to us.
- **Open source.** Every line of code that touches your prompts is public.

> Sieve is in early development. Watch this organization to follow along.
